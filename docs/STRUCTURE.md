Архітектура безстанового скидання пароля на базі JWT

Для забезпечення високої масштабованості та мінімізації навантаження на реляційну базу даних, модуль відновлення пароля реалізовано за патерном Stateless Token без збереження проміжних артефактів (токенів скидання) на персистентному рівні.

Під час ініціалізації запиту, замість генерації випадкового хешу та запису його в базу даних, серверне ядро конструює короткоживучий JSON Web Token (JWT), у корисне навантаження (Payload) якого інкапсулюється ідентифікатор користувача (sub) та семантичний маркер операції (purpose: 'reset-password'). Токен підписується закритим ключем сервера з суворим обмеженням часу життя (Expiration Time, TTL) в 1 годину.

На етапі фіксації нового пароля резолвер здійснює криптографічну перевірку підпису та терміну дії безпосередньо в оперативній пам'яті сервера. Даний архітектурний підхід повністю виключає необхідність проведення транзакцій запису-читання до бази даних для верифікації токенів, усуває проблеми очищення «сміттєвих» застарілих записів та забезпечує захист від атак підміни наміру (Purpose Spoofing) [19, 21].

У результаті користувачі отримали можливість додавати документи безпосередньо через вебінтерфейс системи.

Окрему увагу приділено реалізації механізму адміністративної модерації організацій. Для цього було модернізовано адміністративну панель системи: оновлено таблицю організацій, реалізовано підтримку зміни статусів та додано модальне вікно введення причини модераційної дії. Це дозволило адміністраторам системи вказувати пояснення при відхиленні або зміні статусу організації, що підвищує прозорість процесу верифікації та покращує взаємодію між адміністрацією й користувачами системи.

Крім функціональних змін, було проведено рефакторинг структури застосунку. Видалено застарілі компоненти backend-застосунку, оновлено конфігурацію ініціалізації системи та структуру документації проєкту. Також виконано оновлення залежностей frontend та backend частин системи, що забезпечило сумісність із актуальними версіями бібліотек та покращило стабільність роботи застосунку.

У результаті виконаних змін вебсистема отримала повноцінний механізм верифікації організацій із підтримкою документів та засобами адміністративної модерації, що підвищує рівень довіри до системи та покращує контроль достовірності інформації про організації.
